# ArthroFit

Una aplicación móvil dual diseñada para mejorar la calidad de vida de pacientes con artrosis de rodilla y cadera, facilitando a su vez la monitorización clínica remota por parte de sus médicos. Resuelve la falta de adherencia al tratamiento y la pérdida de seguimiento continuo en patologías articulares crónicas.

## 🛠️ Tecnologías utilizadas

* **Entorno de desarrollo:** Android Studio
* **Lenguaje:** Kotlin
* **Backend y Base de datos:** Firebase (Cloud Firestore / Realtime Database & Authentication)

## ✨ Características principales

* **Perfil de Paciente:** Registro diario de síntomas, escala de dolor y acceso a programas de ejercicios guiados.
* **Perfil de Médico:** Panel de control visual para evaluar la evolución del paciente y su adherencia al tratamiento.
* **Interfaz Accesible:** Diseño optimizado y simplificado para facilitar el uso en pacientes de edad avanzada.
